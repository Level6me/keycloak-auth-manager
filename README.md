# Keycloak Auth Manager - 网站认证与单点登录管理中心

Keycloak Auth Manager 是一款专为站长、开发者与运维人员打造的 **现代化 Web 访问控制与单点登录 (SSO) 管理控制台**。

无需编写复杂的 Nginx 规则或深入钻研 OAuth2 协议，只需通过直观优雅的 Web 控制台，就能为服务器上的任意网站（如内部工具、后台系统、面板、博客等）一键添加 **Apple 风格登录界面**、**全站单点登录 (SSO)**、**Passkey (指纹/面容) 免密登录** 以及 **精细化用户权限控制**。

---

## 🖥️ 控制面板核心功能详述

控制台采用仿 iOS / macOS 的极简美学设计，内置 5 大功能板块，所有操作均支持实时无刷新响应与明暗主题切换。

```
 ┌────────────────────────────────────────────────────────────────────────┐
 │  🌐 站点总览  │  ➕ 添加认证  │  🔒 SSL证书  │  👥 用户权限  │  ⚙️ 系统设置   │
 └────────────────────────────────────────────────────────────────────────┘
```

---

### 1. 🌐 站点总览 (Domain Dashboard)
实时掌握全站安全防护状态，提供卡片流与现代化表格双视图切换：

- **实时状态指标**：直观展示已配置域名总数、拦截保护中站点、HTTPS SSL 开启数与反代运行状态。
- **双视图自由切换**：
  - 🔲 **卡片网格视图**：以大卡片形式展示每个站点的域名、后端目标服务 IP/端口、运行状态指示灯与安全标签。
  - 📑 **表格列表视图**：适合多域名批量检索与密集管理。
- **秒级模糊搜索**：支持在顶部搜索框按域名、端口或后端服务关键词即时过滤筛选。
- **站点控制详情弹窗**：
  - **三大核心功能一键开关**：一键开启/关闭「反向代理」、「SSL 加密」与「身份认证拦截」。
  - **登录方式独立控制**：自由勾选该站点是否允许「Passkey 免密认证」与「用户名密码认证」。
  - **Nginx 配置在线预览与调整**：可视化查看自动生成的反代规则。

---

### 2. ➕ 添加站点认证 (Add Authentication)
仅需填写域名与目标后端端口，几秒内即可完成全套认证防护接入：

- **Cloudflare 智能联动**：
  - 自动拉取 Cloudflare 托管的主域名列表，支持「二级域名前缀 + 下拉选择主域名」快速组合，也支持手动输入完整域名。
  - 可勾选 **自动添加 Cloudflare DNS A 记录** 指向本机服务器，并可一键开启/关闭 CDN 代理加速。
- **后端服务灵活映射**：支持将流量反代至本机任意本地端口（如 `127.0.0.1:8080`）或内网/局域网服务器 IP 与端口。
- **一键全自动建站与证书申请**：
  - 自动联动 1Panel 创建网站与反代目录；
  - 自动配置 OpenResty / Nginx 的 `auth_request` 拦截机制并安全平滑重载；
  - 自动配置并申请 Let's Encrypt SSL 证书，全链路启用 HTTPS。

---

### 3. 🔑 按站点灵活定制登录方式 (Auth Policy)
满足不同站点对安全性与登录体验的不同要求：

| 站点配置模式 | 用户访问时的登录体验 | 适用场景 |
| :--- | :--- | :--- |
| **混合免密模式**<br>*(Passkey 开 / 密码 开)* | 默认显示用户名密码框，下方附带「使用 Passkey 登录」按钮；点击直接在当前页调起生物识别，秒级登录。 | 通用网站、日常办公系统 |
| **纯 Passkey 模式**<br>*(Passkey 开 / 密码 关)* | 用户访问该站点时，**直接呈现纯净的 Passkey 免密卡片**，彻底隐藏密码表单，禁止使用密码绕过。 | 极高安全要求的内部系统、机密后台 |
| **纯密码模式**<br>*(Passkey 关 / 密码 开)* | 用户访问该站点时，**仅显示账号密码登录框**，完全不展示 Passkey 入口。 | 传统账号系统、不支持生物识别的设备 |

---

### 4. 👥 用户与多站点权限管理 (User & Access Management)
直接在控制台内集中管理 Keycloak 用户与细粒度访问权限，无需跳转 Keycloak 后台：

- **用户列表与即时检索**：查看所有注册用户账号、绑定邮箱、账号状态与 Passkey 绑定情况，支持按关键词快速搜索。
- **多站点授权白名单 (`allowed_sites`)**：
  - 为每个用户精准指派可访问的站点列表；
  - 支持「全部站点均可访问」或「仅允许访问特定站点（勾选具体域名）」；
  - 未授权用户即便拥有全局账号，在访问受限站点时也会被自动拦截。
- **一键快捷运维**：
  - **快速新建用户**（支持免邮箱注册）；
  - **一键重置密码**（即时生效，无需邮件验证）；
  - **账号状态切换**（一键启用或禁用账号）；
  - **删除用户**。

---

### 5. 🔒 SSL 证书管理 (SSL Certificate Center)
集中式 HTTPS 证书健康看板：

- **证书状态看板**：汇总展示每个站点的 SSL 开启状态、证书签发机构与剩余有效期天数；
- **到期风险预警**：证书即将过期或失效时自动高亮提醒；
- **一键申请与自动续期**：支持一键为单站点或全部站点批量申请、更新与部署证书。

---

### 6. ⚙️ 系统与全局集成设置 (Settings)
统一管理系统后台与第三方服务的集成参数：

- **Keycloak 服务对接**：配置 Keycloak 服务地址与管理员账号密码，支持连接测试与自适应认证流一键初始化；
- **控制台安全配置**：修改控制台登录账号与密码，内置密码防暴力破解保护；
- **1Panel 集成设置**：配置 1Panel API 端口与 API Key，实现自动建站与配置下发；
- **Cloudflare 全局联动**：配置 Cloudflare API Token 与服务器公网 IP（支持自动嗅探检测）；
- **全站单点登录 (SSO) 作用域**：自动展示当前生效的根域 Cookie 共享清单，实现同根域站点间“一次登录，全网免登”。

---

### 7. 🎨 极致的 UI 体验与设计细节
- **Apple 风格极简界面**：24px 优雅圆角、纯白通透卡片、52px 饱满输入框与内嵌无框眼睛图标，与 Keycloak 原生结构完美融合；
- **主题切换**：支持「自动跟随系统 / 浅色模式 / 深色模式」三态明暗主题自由切换；
- **移动端适配**：针对 iPhone、iPad 与安卓手机进行深度排版适配，支持底部浮动 Dock 栏与手势操作。

## 🚀 快速安装与使用

### 一键全自动部署（推荐）

在服务器终端执行以下命令，脚本将自动检查环境依赖并启动配置向导：

```bash
curl -sSL https://raw.githubusercontent.com/Level6me/keycloak-auth-manager/main/install.sh | bash
```

### 部署完成后访问

- **控制台地址**：`http://你的服务器IP:8088`
- **默认管理员账号**：安装过程中设定的账号密码

---

## 🔄 一键平滑升级

更新过程会自动保留现有的所有站点数据（`data.json`）、系统配置（`config.json`）与加密密钥（`encryption.key`），实现无损热升级：

```bash
curl -sSL https://raw.githubusercontent.com/Level6me/keycloak-auth-manager/main/update.sh | bash
```
